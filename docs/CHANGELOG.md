# Changelog — AI Buyer Frontend

Все заметные изменения frontend фиксируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Версионирование — [Semantic Versioning](https://semver.org/).

## 0.1.0

### Added
- Создан frontend на Vue 3 и Vite.
- Добавлен HTTP-клиент на Axios, централизованная обработка ошибок и модуль управления сессией.
- Добавлены страницы входа и регистрации, защита маршрутов и страница профиля пользователя.
- Добавлен общий интерфейс приложения с боковой навигацией.
- Реализовано управление товарами: список, поиск, фильтрация, сортировка, пагинация, создание, просмотр, редактирование и удаление.
- Добавлено отображение и изменение складских остатков.
- Добавлен учёт продаж: ввод продаж, таблица и сводка за выбранный период.
- Добавлена клиентская логика анализа продаж и остатков, отображение статусов товаров и рекомендаций по закупке.
- Добавлены dashboard с ключевыми показателями и список товаров, требующих закупки.
- Добавлен скрипт заполнения демонстрационными данными (`npm run seed`).
- Добавлена документация по структуре frontend, авторизации, страницам, рекомендациям, истории разработки и запуску.
- Настроен GitHub Actions workflow, выполняющий npm ci и npm run build для Pull Request в main и push в main.

### Changed
- Запросы к backend вынесены в отдельный API-слой, чтобы UI-компоненты не зависели от деталей HTTP-вызовов.
- Для локальной разработки используется Vite proxy для перенаправления `/api` на backend.
- При обновлении товара отправляются только изменённые поля, что позволяет явно различать отсутствие поля и `null`.

### Fixed
- Исправлена привязка dev-сервера к адресу `127.0.0.1`, из-за которой страница могла быть недоступна в локальном окружении.

### Known limitations
- Формула рекомендаций временно выполняется на frontend: в backend существует `RecommendationCalculator`, но REST-эндпоинт рекомендаций ещё не опубликован.
- Модули поставщиков, создания закупок и импорта CSV не реализованы в текущем frontend, поскольку соответствующие возможности пока не поддерживаются backend.
