# Отчёт о тестировании и покрытии кода

## 1. Цель тестирования

Целью тестирования являлась проверка корректности отдельных функций и Vue-компонентов frontend-приложения.

Используются:

- Vitest — запуск тестов;
- Vue Test Utils — взаимодействие с Vue-компонентами;
- jsdom — браузероподобная среда выполнения;
- `@vitest/coverage-v8` — сбор показателей покрытия.

## 2. Конфигурация

Конфигурация тестирования находится в `vitest.config.js`.

Используется среда `jsdom`, позволяющая тестировать компоненты, работающие с DOM. Для сбора покрытия применяется V8 provider. Отчёты формируются в текстовом и HTML-форматах.

В конфигурации перечислены ключевые модули:

- `recommendation.js`;
- `params.js`;
- `fetchAll.js`;
- `errors.js`;
- `StatusBadge.vue`;
- `AppPagination.vue`;
- `ProductForm.vue`;
- `useAnalysis.js`.

## 3. Структура тестов

В проекте создано шесть файлов с тестами:

| Файл                     | Назначение                                    |
| ------------------------ | --------------------------------------------- |
| `AppPagination.test.js`  | Проверка компонента пагинации                 |
| `StatusBadge.test.js`    | Проверка компонента отображения статусов      |
| `errors.test.js`         | Проверка обработки ошибок                     |
| `fetchAll.test.js`       | Проверка загрузки данных с нескольких страниц |
| `params.test.js`         | Проверка формирования параметров запросов     |
| `recommendation.test.js` | Проверка расчёта рекомендаций                 |

Тесты расположены в `src/utils/__tests__/`.

## 4. Проверка Vue-компонентов

### StatusBadge

Тесты `StatusBadge.vue` проверяют корректность отображения статусов. По результатам сбора покрытия компонент достиг 100% покрытия строк, ветвей и функций.

### AppPagination

Тесты `AppPagination.vue` проверяют логику пагинации.

Результаты покрытия:

- строки — 100%;
- функции — 100%;
- ветви — 91,66%.

Неполное покрытие ветвей показывает, что не все возможные условия выполнения компонента были охвачены тестами.

## 6. Дополнительная проверка fetchAll

В ходе дальнейшей работы была переработана функция `fetchAll`. Последовательная загрузка страниц была заменена ограниченной параллельной загрузкой с использованием `p-limit`.

Дополнительно проверялась корректность ограничения количества одновременных запросов.

После исправления тестового набора итоговый запуск `npm run test:run` завершился успешно:

- 6 файлов с тестами;
- 59 из 59 тестов пройдены.

Этот результат получен позднее первоначального отчёта покрытия. Поэтому показатели покрытия выше относятся к запуску на 58 тестах и не должны интерпретироваться как результат пересчёта покрытия после последнего изменения `fetchAll`.

## 7. Вывод

В проекте реализовано автоматизированное модульное тестирование. Проверяются вспомогательные функции, логика расчёта рекомендаций, обработка ошибок, пагинация и отдельные Vue-компоненты.

Полученные результаты подтверждают работоспособность тестового набора. Вместе с тем покрытие всего проекта остаётся неполным, поэтому дальнейшее развитие тестирования целесообразно направить на `ProductForm.vue`, `useAnalysis.js` и оставшиеся непокрытые ветви.
