# 8. Вопросы к защите

Вероятные вопросы и короткие ответы. Ссылки ведут на подробности.

## Общие

**Что делает твоя часть проекта?**
Frontend — веб-интерфейс системы «AI Закупщик». Пользователь регистрируется, ведёт каталог товаров,
остатки и продажи, а система показывает, что нужно закупить и почему.

**Какой стек и почему?**
Vue 3, Vue Router, Axios, Vite. Стек утверждён в описании проекта. Vue простой для старта,
у него понятная реактивность и однофайловые компоненты. → [02-libraries.md](02-libraries.md)

**Что такое SPA?**
Одностраничное приложение: браузер загружает один HTML, а дальше JavaScript сам меняет
содержимое при переходах, без перезагрузки страницы. Переходами управляет Vue Router.

**Как frontend связан с backend?**
Через REST API: HTTP-запросы с JSON. Все запросы собраны в `src/api/`, общий экземпляр axios —
в `src/api/http.js`. → [01-overview.md](01-overview.md)

## Vue

**Что такое компонент?**
Переиспользуемая часть интерфейса в файле `.vue`: скрипт, шаблон и стили.
Например, `AppPagination.vue` используется на трёх страницах.

**Чем `ref` отличается от `reactive`?**
`ref` — обёртка для одного значения, в скрипте доступ через `.value`.
`reactive` — реактивный объект, доступ к полям напрямую. В проекте `reactive` используется для форм.

**Что такое `computed`?**
Значение, вычисляемое из других реактивных данных. Пересчитывается автоматически.
Пример: `visibleRows` в рекомендациях — список с учётом фильтра.

**Как передать данные из родителя в дочерний компонент и обратно?**
Вниз — через props (`defineProps`), вверх — через события (`defineEmits` и `emit`).
Пример: `ProductForm` получает `initial` и отправляет событие `submit` с данными формы.

**Что делает `v-model`?**
Двустороннюю связь поля ввода с переменной: ввёл текст — переменная изменилась, и наоборот.

**Когда загружаются данные страницы?**
В `onMounted` — когда компонент появился на экране.

**Что такое composable?**
Функция с реактивной логикой, которую можно подключить в несколько компонентов.
`useAnalysis()` используется в дашборде и рекомендациях.

## Роутинг и авторизация

**Как защищены страницы от неавторизованных пользователей?**
Навигационный guard `router.beforeEach` проверяет, есть ли действующий токен.
Если нет — перенаправляет на `/login`. → [04-auth.md](04-auth.md)

**Что такое JWT и где он хранится?**
Подписанный токен-«пропуск», который выдаёт backend после входа. Хранится в `localStorage`,
поэтому вход сохраняется после перезагрузки. Живёт 1 час.

**Как токен попадает в запросы?**
Перехватчик axios добавляет заголовок `Authorization: Bearer <токен>` к каждому запросу.

**Что будет, если токен истечёт?**
Роутер не пустит на страницы, а если сервер ответит 401 — перехватчик очистит сессию
и отправит на страницу входа.

**Безопасно ли хранить токен в localStorage?**
Это распространённый и простой вариант для MVP. Минус — токен доступен JavaScript на странице,
поэтому важно не допускать XSS. Vue по умолчанию экранирует вывод `{{ }}`, что защищает от XSS.
Токен короткоживущий (1 час), а при выходе отзывается на сервере.

**Может ли пользователь увидеть данные чужой организации?**
Нет. Backend берёт id организации из подписанного токена и фильтрует все данные по нему.
Это проверка на сервере, а не на клиенте.

## API и данные

**Зачем поле `version`?**
Защита от одновременного редактирования (оптимистичная блокировка). При изменении передаём
версию, которую видели. Если запись уже кто-то изменил — backend вернёт 409, и данные не затрутся.

**Как работает пагинация?**
Backend отдаёт данные по страницам: `items`, `page`, `totalPages`, `totalElements`.
Компонент `AppPagination` переключает страницы, страница перезапрашивает данные с новым `page`.

**Почему PATCH, а не PUT для товара?**
PATCH меняет только переданные поля. Мы отправляем только то, что пользователь изменил.

**Что такое CORS и как его обошли?**
Правило браузера: нельзя без разрешения сервера делать запросы на другой «источник»
(другой порт — тоже другой источник). Backend CORS не разрешает, поэтому dev-сервер Vite
проксирует `/api` на backend: для браузера запросы идут на тот же адрес. В production это делает Nginx.

**Как обрабатываются ошибки?**
Backend возвращает JSON с полем `code`. Функция `errorMessage()` в `src/utils/errors.js`
превращает код в понятный текст. Технические детали пользователю не показываются (NFR-USA-05).

## Рекомендации

**Как считаются рекомендации?**
По продажам за 30 завершённых дней считаются средние продажи в день, точка заказа
(запас на поставку + 7 дней) и целевой запас (поставка + 30 дней). По остатку определяется
состояние, а количество к закупке — это целевой запас минус остаток. → [06-recommendations.md](06-recommendations.md)

**Почему расчёт на frontend, а не на backend?**
Формула в backend уже есть, но REST-метода для неё пока нет. Чтобы показать функциональность,
формула перенесена один в один. Когда появится эндпоинт — расчёт заменится запросом.

**Почему срок поставки всегда 7 дней?**
Это значение по умолчанию в backend, когда поставщик не выбран. Модуля поставщиков пока нет.

**Почему сравнения в формуле умножены на 30?**
Чтобы сравнивать целые числа и избежать ошибок округления дробей на границе состояний.
Так же сделано в backend.

## Что не сделано

**Почему нет поставщиков, закупок и CSV-импорта?**
Backend их пока не поддерживает. Делать экраны, которые никуда не отправляют данные,
не стали — это противоречило бы реальному состоянию системы.

**Что бы ты сделал дальше?**
Поставщики, закупки и импорт — когда они появятся в backend; замена клиентского расчёта
на серверный; бюджет на дашборде. → [07-development-log.md](07-development-log.md)

## Практические задания, которые могут попросить

**Покажи, где добавить новую страницу.**
1. Создать компонент в `src/views/`.
2. Добавить маршрут в `src/router/index.js`.
3. Добавить пункт в массив `links` в `src/components/AppSidebar.vue`.

**Покажи, где добавить новый запрос к API.**
Добавить функцию в нужный файл `src/api/` по образцу соседних, используя `http`.

**Поменяй основной цвет интерфейса.**
Переменная `--primary` в начале `src/assets/main.css`.

**Добавь новый текст ошибки.**
Объект `MESSAGES` в `src/utils/errors.js`.
